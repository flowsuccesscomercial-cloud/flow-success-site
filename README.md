# Site Flow Success

Site institucional da Flow Success. Projeto do Flow Web Studio.

## Arquivos
- `index.html`: página principal
- `config.js`: WhatsApp, formulário, e-mail, Instagram e mensagens prontas (altere só aqui)
- `politica-privacidade.html`: política de privacidade (preencher o que está entre colchetes)
- `assets/`: logo, ícones, elementos gráficos e imagem de compartilhamento

## Ramos
- `main`: versão publicada
- `v2`: nova versão, aguardando aprovação para publicação
